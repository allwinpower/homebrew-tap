# allwinpower/homebrew-tap

Homebrew formulae for [sshuttle2](https://github.com/allwinpower/sshuttle2), a VPN over a plain SSH login.

```bash
brew install allwinpower/tap/sshuttle2
```

It works on macOS (Apple Silicon and Intel) and on Linux (x86_64 and arm64). The formula installs the prebuilt binary from the sshuttle2 GitHub Release and checks its SHA-256.

sshuttle2's release workflow updates `Formula/sshuttle2.rb` for every release, so don't edit it here.

The formula arrives with sshuttle2's first release (0.1.0).
